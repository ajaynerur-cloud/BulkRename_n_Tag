# NameTag for Android

This folder is a complete Android Studio / Gradle project that wraps the NameTag web app as a
**Trusted Web Activity** (TWA): a real Android app that runs the site full screen in Chrome's engine,
with its own launcher icon, splash screen, shortcuts and a place in the Android share sheet.

It was generated by `scripts/android/generate-project.mjs` (Bubblewrap's generator) and is built
by `.github/workflows/android.yml`. Settings are read from environment variables at build time:

| Variable | Meaning | Default |
| --- | --- | --- |
| `PWA_HOST` | Domain of the deployed site, e.g. `nametag-abcd.onrender.com` | `nametag.onrender.com` |
| `ANDROID_PACKAGE_ID` | Application id | `app.nametag.twa` |
| `ANDROID_VERSION_NAME` / `ANDROID_VERSION_CODE` | Version shown to users / increasing build number | `1.1.0` / `1` |
| `ANDROID_KEYSTORE_FILE`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD` | Release signing | unsigned if not set |

Build locally (JDK 17 and the Android SDK required):

```bash
cd android
PWA_HOST=your-site.onrender.com ANDROID_KEYSTORE_FILE=/path/nametag.keystore \
ANDROID_KEYSTORE_PASSWORD=... ANDROID_KEY_PASSWORD=... ./gradlew assembleRelease bundleRelease
```

After changing icons, colours or the web manifest, regenerate with `npm run android:generate`
(needs `npm install` for the dev dependencies). `store/play-store-icon-512.png` is the Play Store listing icon.
